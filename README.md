# Medical-Store-Management-system
A console-based Medical Store Management System developed using Java, JDBC, and MySQL (XAMPP). This project helps manage medicine records, stock availability, sales, and billing operations efficiently through a simple command-line interface. It demonstrates database connectivity, CRUD operations, and real-time inventory handling.

## 🚀 Features
- User authentication (login & logout)
- Role-based access (Admin / User)
- Medicine inventory management
- Billing system with text-file invoice generation
- MySQL database integration
- Clean and modular Flask architecture
